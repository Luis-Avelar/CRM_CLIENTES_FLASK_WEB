#  CRM Clientes Web (Flask)

Aplicación web tipo CRM para gestionar clientes, desarrollada con **Python, Flask y SQLite**.

---

## 🧠 Funcionalidades

- ➕ Agregar clientes
- 📋 Ver lista de clientes
- ✏️ Editar clientes
- ❌ Eliminar clientes
- 💾 Persistencia con SQLite

---

## 🛠️ Tecnologías usadas

- Python 3
- Flask
- SQLite
- Bootstrap 5

---

## 📸 Vista previa

Interfaz simple tipo CRM con formulario y tabla dinámica.

---
