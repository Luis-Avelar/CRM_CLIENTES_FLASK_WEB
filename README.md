#  CRM Clientes Web (Flask)

Aplicación web tipo CRM para gestionar clientes, desarrollada con **Python, Flask y SQLite**.

---

## 🧠 Funcionalidades

- ➕ Agregar clientes
- 📋 Ver lista de clientes
- ✏️ Editar clientes
- ❌ Eliminar clientes
- 💾 Persistencia con SQLite

---

## 🛠️ Tecnologías usadas

- Python 3
- Flask
- SQLite
- Bootstrap 5

---

## 📸 Vista previa

Interfaz simple tipo CRM con formulario y tabla dinámica.

---

## ⚙️ Instalación

```bash
git clone https://github.com/Luis-Avelar/CRM_CLIENTES_FLASK_WEB.git
cd CRM_CLIENTES_FLASK_WEB
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
